# Changelog

## v0.1.0-beta.1

Initial public experimental release for WoW Forever 1.60.1.70450.

- Free camera, optional visible character and adjustable lens/speed.
- Waypoint editing, drag reordering, smooth/straight playback and selected start.
- View distance, fog, rendering, world time, lighting, sky and weather controls.
- Charcoal interface, dark-blue eye logo and matching header/window icons.
- Slow motion and unfinished target/attachment features remain disabled.
- Source, build instructions, license and account-risk documentation included.
