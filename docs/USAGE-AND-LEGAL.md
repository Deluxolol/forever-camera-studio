# Usage and legal information

This is an experimental camera tool, not a Blizzard-authorized addon. It reads
and writes camera and environment data in the running client. The current
implementation does not require remote executable patches or remote function
calls. That does not make it permitted, undetectable, or safe from account action.

Blizzard's EULA restricts unauthorized access/modification, gameplay-altering
third-party tools and unauthorized reading of platform data. Blizzard has also
stated that prohibited client modifications can lead to permanent account closure.
No permission or exemption has been obtained for this project. Filmmaking use,
free distribution, or a beta client should not be treated as authorization.

- [Blizzard End User License Agreement](https://www.blizzard.com/en-gb/legal/08b946df-660a-40e4-a072-1fbde65173b1/blizzard-end-user-license-agreement)
- [Blizzard: Prohibitions on Third-party Software](https://eu.forums.blizzard.com/en/wow/t/prohibitions-on-third-party-software/583048)

Contractual permission, copyright law and criminal law are separate questions.
EU judgment C-159/23 addresses the limited copyright question of variable data
in RAM; it is not a general authorization to use this tool with an online game.
This document is not a legal opinion or a guarantee about any jurisdiction.

- [CJEU C-159/23, judgment of 17 October 2024](https://eur-lex.europa.eu/legal-content/EN/TXT/PDF/?uri=CELEX%3A62023CA0159)

Request explicit permission from the game operator before use. Obtain qualified
legal advice for your situation if needed, especially before commercial use.

Save your routes before closing or testing. F10 and normal application close
attempt to restore owned temporary settings. A force-quit, crash or changed
client state can prevent restoration; restart the game if necessary.
